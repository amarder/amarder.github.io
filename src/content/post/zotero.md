I like managing references with [Zotero](https://www.zotero.org/). My setup is fairly straightforward:

I used to like importing references using their [browser extension](https://www.zotero.org/download/connectors), but it hasn't been saving attaching pdf files properly for me. I've moved over to using the magic wand button in the app or [your web library](https://www.zotero.org/mylibrary) works even better.

Personally, I like storing all my pdf files in Dropbox so it's easy to pull them up on my tablet. I use [ZotMoov](https://github.com/wileyyugioh/zotmoov) to do this. I found [this guide from Berkeley](https://guides.lib.berkeley.edu/zotero/zotfile) helpful. One gotcha to watch out for: ZotMoov doesn't handle attachments in group libraries particularly well, right now I'm using it on "My Library" only.
