I use [Zotero](https://www.zotero.org/) for managing academic references. My setup is relatively straightforward but works well for me.

## Desktop

1. **Install [Zotero](https://www.zotero.org/download/) on your computer.**

   I used to import references using their [browser extension](https://www.zotero.org/download/connectors), but it hasn't been attaching PDF files properly for me lately. I've switched to using the magic wand button in the desktop app, which seems to be more reliable.

2. **Install the [ZotMoov](https://github.com/wileyyugioh/zotmoov) plugin in Zotero.**

   I like storing all my PDF files in Dropbox so I can easily access them on my tablet. That's why I use ZotMoov to automatically move PDFs to a designated folder. I found [this guide from the UC Berkeley Library](https://guides.lib.berkeley.edu/zotero/zotfile) helpful for setting up ZotMoov. 
   
   **Warning**: ZotMoov doesn't handle attachments in group libraries well, so I only use it with "My Library".

## Mobile

On my phone, I access Zotero through [the web library](https://www.zotero.org/mylibrary). I haven't found the Android app to offer any significant advantages over the web interface.
