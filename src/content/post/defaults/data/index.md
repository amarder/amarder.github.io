Over 500 blog posts have been added to this [App Defaults page](https://defaults.rknight.me/). I scraped them all, used `gpt-4o-mini` to extract the apps discussed on each page, and had Claude Opus 4.5 build an interface to browse the data. The data is still a little messy, but I enjoy the bird's eye view. Here are my takeaways:

- There are a lot of Apple users - fewer Android users than I expected.
- [Fastmail](https://www.fastmail.com/) is a surprisingly popular email provider.
- [Things](https://culturedcode.com/things/) (Apple only) is a very popular to-do app.
- [1Password](https://1password.com/) is more popular than I expected; I use [Bitwarden](https://bitwarden.com/).

Let's get more Android and Linux users on the [/defaults](https://slashpages.net/#defaults) train!
